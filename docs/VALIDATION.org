* Desktop scenarios exercised
- First launch, folder-picker wiring with a stubbed native selection, cancellation,
  folder changes, and per-library syntax preferences.
- Recursive prefix search, duplicate titles, keyboard creation and immediate Enter,
  source editing, rename, and restart persistence.
- Vim toggle, Normal/Insert editing, :w, undo, all four themes, heading font,
  content width, and all three .txt syntax selections without rewriting files.
- Local and remote images, synthetic clipboard image paste without changing the
  system clipboard, native file-backed drops, Mermaid, inert raw HTML, and sandbox.
- Outside saves and conflicts, Keep both, close-to-background with pending edits,
  single-instance reopening, shortcut registration failure handling, and renderer
  view reconstruction from main-owned buffers.

Backend tests separately cover actual subprocess crash-journal recovery,
Use disk, outside deletion, injected write failures, save races, UTF-8/BOM/EOL
preservation, path safety, portable filename collisions, and parser/resource limits.
The system Trash callback is verified through injected test operations; manual
native Trash behavior remains a platform check.
