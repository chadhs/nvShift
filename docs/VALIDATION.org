#+title: nvShift validation

* First public release, v0.1.0
This version includes all earlier development milestones plus manual asset
cleanup and hosted build/release automation. Earlier local 0.1.x binaries are
archived under the ignored =release/development-*= folder and are not public
release candidates. Git history is preserved; version manifests start the
public sequence at =0.1.0=.

Local macOS arm64 checks on 2026-10-27 pass all 203 tests and the production
renderer, analyzer, and standalone uncapped cleanup-worker bundle checks.
The 10,000-note benchmark measured 839.47 ms indexing, 14.06 ms median search,
and 20.57 ms p95, below the 100 ms target. The runtime license inventory still
contains 215 packages, with the existing BSD-3-Clause application license.

Nineteen cleanup cases cover shared/uncapped references, all syntax settings,
linked notes, encoded and extensionless aliases, recovery groups, Undo/import
pins, stale files, mid-batch new notes/recovery records, and Trash failures.
A 144 MiB recovery history completes in a process with a 96 MiB heap, proving
that the full recovery corpus is not retained in the main process. Fourteen
release cases verify versioning, bootstrap/trusted-event guards, exact artifacts,
checksums, drafts/retries, immutable publication, and source/tag mapping.

Development Electron smoke covers the new review dialog, thumbnails, zero
initial selections, Select all rules, selected totals, partial Trash failures,
stale results, Undo/import protection, and restart behavior. Its Trash fixture
only moves temporary test assets; native system Trash remains a manual check.
The fresh public-version arm64 DMG and ZIP pass extracted-package Electron
smoke and mounted-DMG signature, identity, payload, BSD-3-Clause license, and
Electron notice checks through =npm run test:package:mac=.

Workflow YAML parses and actionlint 1.7.12 passes with the single unsupported
=concurrency.queue= keyword excluded. The =queue: max= setting is documented in
[[https://docs.github.com/en/actions/how-tos/write-workflows/choose-when-workflows-run/control-workflow-concurrency][GitHub's concurrency documentation]] and keeps pending releases queued.

Hosted macOS/Linux/Windows run summaries and the release's native-validation
link establish results after GitHub bootstrap; local configuration alone does
not establish native runner results. Publication remains gated until those
jobs succeed. Interactive Wayland, physical shortcuts, picker interactions,
native Trash, and Intel Mac checks remain pending until actually executed.

  image previews, linked-note navigation, folder-wide .txt modes, and native image
