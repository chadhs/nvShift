Org is plain text with a little structure. Headings begin with stars,
links keep their labels close, and a list is just a list. It works in
Emacs, in your favorite editor, and on the back of an envelope.

This is *markup-preview*: a live reader for your Org and Markdown files. Open a file,
keep writing in your editor, and watch this page follow along when you save.

#+begin_quote
The file is yours. The editor is your choice.
#+end_quote

* Code stays code

* Bring your own notebook
Use the Open file button, drop several =.org= files onto this window, or launch
from the terminal with file paths. Each file opens in its own tab. Edit it elsewhere and save. The preview
keeps its scroll position as your document changes.

#+begin_src sh
npm run dev -- ~/notes/today.org ~/notes/project.org
#+end_src

Switch tabs with =Ctrl+Tab= or =Ctrl+Shift+Tab=. Each tab remembers your place.
Local images display inline. Links to other Org and Markdown documents open
in tabs. Try [[file:welcome.md#code-and-diagrams][the Markdown notebook]].
Math rendering and full Emacs export compatibility remain outside this release.
